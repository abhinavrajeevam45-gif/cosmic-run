▶ ARCHITECTURE OVERHAUL
  ─────────────────────
  • Introduced generate_premium_game.py as the MASTER SOURCE FILE
    — All game code is authored in the Python generator, which writes
      a fully self-contained index.html on each run.
  • build_cosmic_run.py refactored to thin 10-line wrapper that
    delegates entirely to generate_premium_game.py.
  • Vite 6.4.6 dev server + production build pipeline retained.
    npm run build produces dist/ with gzipped JS (~147 KB).
  • Three.js 0.170.0 loaded via ES importmap from esm.sh CDN —
    no local copy needed.

▶ 3D ENVIRONMENT IMPROVEMENTS
  ────────────────────────────
  • 10 distinct sector environments (Earth → Deep Space Heliopause)
    with per-sector background color, fog, sun light color/intensity,
    and planet configuration.
  • Procedural planet texture generation using Canvas 2D:
    — Earth: continent blobs, ocean, Greenland ice, storm swirls,
      city-light glitter layer, Rayleigh atmospheric halo.
    — Moon: crater fields with shadow gradients.
    — Mars: rust red with darker terrain patches.
    — Jupiter: banded cloud belts with Great Red Spot ellipse.
    — Saturn: ring system (torus geometry, opacity-mapped).
    — Gas giants, ice giants with layered gradient textures.
  • ISS Space Station mesh: main body + 4 solar panel wings with
    orbit animation in Earth hangar scene.
  • Earth cloud sphere: separate semi-transparent cloud layer with
    offset rotation for parallax effect.
  • 180-particle space dust system: streaks toward camera at speed-
    scaled velocity; hidden in hangar, visible during flight.
  • Hyperspace Warp Gate portals: torus geometry + wireframe ring,
    animated rotation, spawns 80 units ahead of ship at sector
    threshold, triggers sector transition on pass-through.
  • 400 procedurally placed star field (Points geometry).

▶ SPACESHIP MODELS (5 SHIPS)
  ──────────────────────────
  • Orion X-1: Classic delta interceptor (balanced stats)
  • Valkyrie: Forward-swept wing fighter (+speed, 1.08× bonus)
  • Aurora: Faceted lifting body with angled surfaces (+agility)
  • Titan: Twin-hull catamaran with cross-bracing (+1 shield pip)
  • Quantum: Needle-thin hull with animated torus rings (+magnet)
  • All ships: dual-layer engine flames (outer envelope + white core)
    with dynamic scale pulsing (boost = 2.4× scale)
  • Hangar drag rotation: mousedown/move enables 3D ship inspection
  • Aerodynamic banking: roll on lane change, pitch on jump/dive
  • Ships purchasable with in-game coins; persistent across sessions

▶ GAMEPLAY MECHANICS
  ──────────────────
  • 3-lane system (left/center/right) with smooth X interpolation
  • Vertical jump (Y=+5.5) and dive (Y=-1.5) with spring return
  • Nitro Boost: 1.75× speed multiplier + shield immunity
  • 3 obstacle types: rotating asteroids, spinning debris, lasers
  • Energy gates: score bonus on clean pass-through
  • 4 power-up types: Boost, Shield, Coin Magnet, Score Doubler
  • Each power-up has 5 upgrade levels in the Upgrade Bay
  • Safe breathing zones: guaranteed gap every 3 chunks

▶ NEAR-MISS & COMBO SYSTEM
  ──────────────────────────
  • Near-miss detection: side-pass within 1.4–2.6 units dx from obstacle
  • Combo multiplier builds 1× → 5× on consecutive near-misses
  • Combo resets to 1× on any collision
  • Near-miss toast shows "+N PTS" scaled to current combo level
  • Combo badge (2× COMBO 🔥 through 5× COMBO 🔥) in HUD

▶ LEVEL PROGRESSION
  ──────────────────
  • 10 sectors with progressive warp distance thresholds
  • Sector Progress Bar in HUD shows % to next warp gate
  • Warp portal spawns 80M before threshold, waits at center lane
  • Passing portal triggers: sector switch, planet rebuild, speed ramp,
    hyperspace sound, camera shake, XP reward, science toast
  • Warp count tracked in career stats (totalWarps)
  • Max combo tracked in career stats (maxCombo)

▶ MISSIONS SYSTEM
  ──────────────
  • Random mission per run: reach X distance OR collect X coins
  • Mission tracker visible in HUD (progress bar + objective text)
  • Auto-detects both conditions satisfied simultaneously
  • Reward on completion: +100 Coins + +200 XP (toast notification)
  • Single claim per run (runMissionClaimed flag)

▶ NASA SCIENCE INTEGRATION

  • Science toast also fires on: level launch, warp transit, achievements,

  • NASA Solar System Encyclopedia modal: full fact sheets for all bodies

▶ XP, RANKS & ACHIEVEMENTS

▶ AUDIO ENGINE (ZERO EXTERNAL FILES)
  ─────────────────────────────────
  • SoundEngine: 8 procedural SFX via Web Audio API OscillatorNode
    — playCoin: harmonic FM with combo pitch scaling
    — playNearMiss: adrenaline sweep (880Hz → 1760Hz)
    — playLaneSwitch: short directional click
    — playJump: ascending glide (220Hz → 660Hz)
    — playDive: descending plunge (660Hz → 180Hz)
    — playPowerup: power chord triad (C-E-G) with reverb
    — playWarpJump: bass thunder + harmonic climb
    — playShieldDeflect: metallic triangle ping
    — playCrash: low distorted impact
    — updateEngine: continuous speed-scaled engine rumble
  • MusicEngine: procedural synthwave loop
    — Kick drum (sine-based, 60ms decay)
    — Hi-hat (white noise bandpass)
    — Bassline (sawtooth, 4-note walking bass)
    — Cosmic arpeggio (sine, 16-note pattern)
    — 3 modes: hangar (ambient), game (full beat), boost (high energy)
    — Low-pass filter during pause (500Hz cutoff) for muffled effect
  • SFX and music volume independently adjustable in pause menu
